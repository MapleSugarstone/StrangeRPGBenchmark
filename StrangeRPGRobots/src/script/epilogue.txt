# who holds the Wall and the city, the Bailers, the Dry Plan, the port, each companion, each faction by standing,
# the hero's background, and the hero's own fate. Slides that need people set an ep_ flag while the screen is
# dark, so the map shows them already standing there. Notes: Notes/replay-b-notes.md.
