The Tuner's Knot Key

On the Drop, a line can carry words. Each letter is a knot: one to three turns, with the lead going to the left or to the right. A plain turn (the light loop) is called overhand. A turn with a cross in it (the green loop) is called crossed. A stretch of bare line is a space. Two stretches end a sentence.

Fathom's fallen line is written in this key. So are a few lines in the game that nobody reads aloud. If you can see the knots, you can read them with this page. Try the title screen.

How the game draws them

The glyph strings in the game's code use > and < for the lead side, o for an overhand turn, x for a crossed turn, and - for bare line. The letter A is >o: lead right, one overhand turn.
